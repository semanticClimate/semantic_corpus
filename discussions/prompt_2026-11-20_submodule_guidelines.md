## Prompt (verbatim)

We need clear guidelines for submodules. These should govern 
* documentation
* tests
* code:
  - launcher (CLI, and usable by a GUI such as streamlit)
  - operational code
  - code quality
  - CI/CD
* declarative files (yaml)
* project management
  - branches
  - testing

Please suggest additional necessary components.
