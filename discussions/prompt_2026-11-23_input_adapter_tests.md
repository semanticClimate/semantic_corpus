## Prompt (verbatim)

Please write examples/tests for these conversions. example docs should  be relatively small but should test at least:
* start page
* end page
* recto and verso
* headers and footers including page numbers and running titles
* floats (images and text)
* font variations: size and include some bold and italic examples
* diacritics, and greek characters. simple devanagari

Please review and suggest omissions
